# Security Policy

## 1. Supported versions

| Version | Supported |
| ------- | --------- |
| Latest release on PyPI | Yes |
| Older releases | No |

## 2. Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities by email to [carlos@danube.ai](mailto:carlos@danube.ai). Include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof-of-concept.
- The affected version(s).

We will acknowledge receipt within 48 hours and aim to release a fix within 14 days for confirmed vulnerabilities. We will credit reporters in the release notes unless anonymity is requested.
